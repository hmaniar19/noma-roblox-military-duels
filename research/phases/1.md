# Phase 1: Core duel

Goal: one map with real 1v1 duels that are fair and can't be cheated. Press Play alone in Studio and you duel a bot.

In scope (brief sections 1, 5, 7):
1. **Map:** a playable Shooting Range built from code. It has the central tower, at least one two-story building and some hills or dips. Both sides must be reachable.
2. **1v1 match flow:**
   - First to 5 round wins.
   - Each round has a 2:00 timer. If time runs out the round is a draw: no point, plus a simple "DRAW" message (no cutscene yet).
   - At 4–4 the round is labeled "SUDDEN DEATH". The special loadout comes in phase 2.
   - Teams swap sides every round.
   - 3-second spawn shield that drops early if you fire.
   - Leaving mid-match counts as a loss.
3. **Solo play:** if only one human is present, a server-controlled bot fills the other slot. The bot moves, takes cover and shoots under the same server rules as players.
4. **Assault rifle only**, with server-side magazine, reload and fire-rate.
5. **Combat:**
   - 100 HP. Head ×3, Body ×1, Legs ×0.5.
   - Exact hitboxes on a standard uniform rig that is the same size for everyone. Player avatars wear Navy Blue or Azure Grey with gold or white armbands.
6. **Server authority:**
   - The client sends only intent: fire with origin and direction, and the requested movement.
   - The server re-raycasts every shot from the shooter's validated position, rejects shots that go through walls, and checks that the aim direction matches the server-tracked look direction within a tolerance.
   - The server checks movement speed and teleporting.
   - Out-of-bounds volumes send players back.
   - Each rejected action adds a cheat flag. Phase 6 adds the penalties.
7. **Minimal HUD:** health, ammo, round score, timer, and a hit marker plus a red "HEADSHOT" flash.
